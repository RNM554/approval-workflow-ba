# Internal Approval Workflow Management System (Business Analysis)

> **Note:** Academic project with simulated business scenarios and mock data.

## Overview
A Business Process Management (BPM) web application designed to digitize manual, paper-based purchasing proposals and leave requests through a multi-level dynamic approval workflow (`Submit → Review → Approve/Reject/Timeout`).
